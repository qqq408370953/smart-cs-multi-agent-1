# Agent Flow Lab

面向学习者的智能客服Agent执行流程可视化客户端。它不复制后端业务逻辑，而是调用`node-impl`的真实API，再将一次完整请求拆成八个可观察步骤。

## 功能

- 产品咨询、退款工单、账户安全、合规拦截四个场景按钮
- 单步执行、点击指定步骤、自动播放和重置
- 八课学习计划，以及每一步对应的详细讲解弹框
- 弹框内提供真实执行说明、输入输出、核心概念、当前运行数据和掌握标准
- 关键源码文件、准确行号、代码片段和GitHub定位链接
- LangGraph节点的等待、执行、完成与未选分支状态
- 实时查看共享State、接口Result和事件日志
- 验证健康检查、意图路由、业务Agent、合规、最终响应、会话历史、指标与MCP工具
- 支持修改API地址和自定义用户消息
- 响应式布局，可在桌面和移动端使用
- 支持时注册`run_agent_flow_demo` WebMCP工具

## 启动

先启动Agent后端：

```bash
cd ../node-impl
npm start
```

再开一个终端启动前端：

```bash
cd ../agent-flow-demo
npm start
```

浏览器访问：

```text
http://localhost:8200
```

默认连接`http://localhost:8100`。如后端运行在其他地址，可直接修改页面右上角的Agent API输入框。

## 推荐演示顺序

1. 点击“学习计划 / 8课”，先阅读当前课程目标和关键概念。
2. 选择“产品咨询”，在弹框中点击“执行到本步”，逐步观察正常RAG链路。
3. 每执行一步，切换State、Result、Events，对照弹框里的“当前运行观察”。
4. 使用每条步骤右侧的“讲解”按钮，查看准确源码行号和关键代码。
5. 完成八课后，选择“退款工单”，观察条件边切换到Ticket Agent。
6. 选择“账户安全”和“合规拦截”，比较Security分支与合规拒答。
7. 修改消息，先预测路由结果，再执行验证自己的判断。

## 八课学习计划

| 阶段 | 课程 | 建议目标 |
| --- | --- | --- |
| 基础入口 | 1. API连接 | 理解HTTP边界和健康检查 |
| 基础入口 | 2. 创建State | 掌握LangGraph共享数据契约 |
| 基础入口 | 3. 意图路由 | 掌握结构化分类、规则降级和条件边 |
| 核心智能 | 4. 专业Agent | 掌握RAG主链路，并比较Ticket/Security |
| 核心智能 | 5. 合规统一出口 | 掌握规则、LLM二阶段审查和fail-closed |
| 核心智能 | 6. Supervisor合成 | 理解内部State如何变成外部响应 |
| 状态能力 | 7. 记忆与Checkpoint | 区分短期历史和LangGraph图状态 |
| 工程化 | 8. Tracing与MCP | 用指标、Span和工具Schema观察系统 |

## 重要说明

`POST /api/chat`会在后端一次性执行完整LangGraph。前端为了教学，将同一次真实结果拆成多个观察阶段；它不会伪造不存在的逐节点HTTP接口。

“会话记忆”步骤读取的是`GET /api/history/:sessionId`短期历史。LangGraph Checkpoint保存在后端`MemorySaver`中，目前没有公开HTTP查询入口，两者不要混为一谈。
